# Data Architecture & Rules for `src/data`

## ⚠️ STRICT RULE: 100% Complete Authentic Data (Zero-Summary Policy)
As defined in [PROJECT_GUIDELINES.md](../../PROJECT_GUIDELINES.md), every scripture, stotra, grantha, puja, chalisa, and ritual text in this directory must contain its **entire authentic text**:

1. **NO SAMPLE VERSES**: Never add only 1-2 verses followed by a summary or ellipsis.
2. **ASHTAKS**: Must contain all 8 verses + phala stuti (9 total).
3. **PACHISI**: Must contain all 25 verses.
4. **GRANTHAS**: Must contain full original verses/gathas/sutras with accurate line-by-line Hindi meanings.
5. **CHALISAS**: Must contain all 40 chaupais and dohas.
6. **PUJAS**: Must contain full sthapana, ashtak dravyas, jaimala, and visarjan.

Any incomplete entry breaks user trust and violates project integrity.
