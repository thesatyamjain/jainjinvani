## 2026-09-21 - Hardcoded Offline Recovery Codes\n**Vulnerability:** Found plaintext offline recovery codes ('JIN-8492-SAFE', etc.) exposed in the AdminLogin component's UI, directly violating the intended zero-knowledge hash-based security design.\n**Learning:** In purely client-side applications, static mock data in the UI can inadvertently leak high-value secrets. Developer assumptions about 'dummy data' in setup screens might actually represent valid credentials.\n**Prevention:** Never embed plaintext fallback secrets or keys directly in React components. Always use placeholders like 'JIN-****-****' when demonstrating format, keeping the actual values purely offline and their hashes in the codebase.
